# Pug — Desktop Pet

ตัวการ์ตูน pixel art เดินเล่นอยู่บนจอ Mac

## ส่งให้แฟน

1. ส่งไฟล์ `Pug.zip` (AirDrop, LINE หรือ Drive ก็ได้)
2. แฟนดับเบิลคลิกแตกไฟล์ แล้วลาก `Pug.app` ไปไว้ในโฟลเดอร์ Applications
3. ตอนเปิดครั้งแรก Mac จะเตือนว่า "ไม่รู้จักผู้พัฒนา" เพราะแอปไม่ได้ซื้อใบรับรองจาก Apple ให้ทำแบบนี้:
   - กด Done/OK ที่หน้าต่างเตือน
   - ไปที่ System Settings → Privacy & Security เลื่อนลงล่างสุด กด **Open Anyway**
   - เปิดแอปอีกครั้ง แล้วกด Open
4. ตัวจะตกลงมาจากข้างบนจอแล้วโบกมือทักทาย ตั้งแต่นั้นจะเปิดเองทุกครั้งที่เปิดเครื่อง

## เล่นยังไง

| ทำอะไร | เกิดอะไรขึ้น |
|---|---|
| ปล่อยไว้เฉยๆ | ยืนหายใจ กะพริบตา เดินเล่นไปมาช้าๆ |
| คลิก 1 ที | จั๊กจี้ หัวเราะ มีหัวใจลอย |
| คลิกรัวๆ 6 ที | มึนหัว ตากากบาท ดาววนหัว |
| กดค้าง / ลาก | ถูกยกขึ้น ตัวแกว่งตามเมาส์ |
| ยกสูงแล้วปล่อย | ตกลงพื้น ตัวยุบแล้วเด้ง (ตกแรงๆ จะมึน) |
| ยกแล้วเขย่าแรงๆ | ตกใจ เหงื่อตก ลงพื้นแล้วมึน |
| ลากแล้วเหวี่ยง | ลอยไปชนขอบจอแล้วเด้งกลับ |
| ไม่มีใครเล่นด้วย 3 นาที | หาว พูด "ฝันดีน้าา" "คิดถึงนะ" "โทรมาหาได้น้าา" แล้วนอนหลับ |
| คลิกตอนหลับ | ตื่นงัวเงีย |

นานๆ ที (20–40 นาที) จะพูดข้อความสุ่มเอง

คลิกขวาที่ตัว หรือคลิกไอคอนหน้าบน menu bar ด้านบนจอ จะมีเมนู: ซ่อนตัว, เรียกมาหา, พูดอะไรหน่อย, ให้นอนเลย, ขนาด, เวลาง่วง, เดินเล่น, แก้ไขข้อความ, เปิดเองตอนเปิดเครื่อง, ออก

## แก้ข้อความ

เมนู → **แก้ไขข้อความ…** จะเปิดไฟล์ใน TextEdit แก้ในวงเล็บ `[ ]` ได้เลย บันทึกแล้วมีผลทันที
(ไฟล์อยู่ที่ `~/Library/Application Support/Pug/messages.json` ถ้าแก้พังแอปจะใช้ข้อความเดิมแทน)

## สำหรับคนทำ

- `./build.sh` ทำทุกอย่างในคำสั่งเดียว: ดึงภาพจาก `reference/` → ประกอบท่า → สร้าง `build/Pug.app` (Apple Silicon + Intel, macOS 12+)
- `build/Pug.app/Contents/MacOS/Pug --record demo [ชื่อคลิป]` อัดคลิปตัวอย่างลง `demo/` (ต้องมี ffmpeg)

โครงสร้าง:

- `reference/` รูปต้นฉบับ: `sheet3.png` (ตัว ท่าเดิน มุมข้าง), `expressions.png` (สีหน้า 11 แบบ), `yawn.jpg` (หน้าหาว), `outfits.png` (ชุด สำหรับฟีเจอร์เปลี่ยนชุดภายหลัง)
- `tools/extract.py` ตัดตัวละครออกจากรูป แปะสีหน้าใหม่ → `art/parts/`
- `tools/poses.py` ประกอบทุกท่า (ยืน เดิน หัวเราะ ถูกยก ตก มึน นอนห่มผ้า)
- `tools/effects.py` หัวใจ ดาว Zzz แบบ pixel, `tools/build_sprites.py` รวมเป็น atlas ใน `App/Resources/sprites/`, `tools/make_icon.py` ไอคอนแอป
- `App/Sources/` โค้ด Swift: `Engine.swift` พฤติกรรมและฟิสิกส์, `Renderer.swift` วาดตัว กล่องคำพูด เอฟเฟกต์, `App.swift` หน้าต่างและเมนู, `Messages.swift` ข้อความ, `Recorder.swift` อัดคลิป
